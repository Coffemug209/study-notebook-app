# PART 01 — PROJECT BOOTSTRAP & TOOLING

## Objective

Create the initial React/Vite + Express/TypeScript project structure and install the core
dependencies without implementing product features.

## Prerequisites

None. Read PART-00 first.

## Scope

- initialize the repository;
- create `client/` and `server/`;
- configure TypeScript;
- configure Vite;
- configure Tailwind;
- install React Router and Axios;
- install Express and server tooling;
- install Prisma packages;
- install Tiptap packages;
- install UploadThing packages required for the planned integration;
- create environment example files;
- create basic client/server scripts.

## Do Not

- create database models beyond placeholders;
- implement notes;
- implement subject tabs;
- implement authentication;
- implement dashboard;
- add unrelated UI.

## Acceptance Checklist

- [ ] client starts successfully;
- [ ] server starts successfully;
- [ ] TypeScript checks pass;
- [ ] client can call a temporary health endpoint;
- [ ] `.env.example` exists;
- [ ] secrets are not committed;
- [ ] project structure matches FOUNDATION.
