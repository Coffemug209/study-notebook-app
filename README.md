# Study Organizer

A personal notebook-first study organizer web application built with React, Vite, TypeScript, Tailwind CSS, Express, Prisma, Neon PostgreSQL, Tiptap, and UploadThing.

## Architecture

- **Client (`/client`)**: React 19 + TypeScript + Vite + Tailwind CSS + Tiptap + UploadThing
- **Server (`/server`)**: Node.js + Express 5 + TypeScript + Prisma ORM + Neon PostgreSQL

## Development

```bash
# Run server
npm run dev:server

# Run client
npm run dev:client

# Typecheck both client and server
npm run typecheck

# Build both client and server
npm run build
```
